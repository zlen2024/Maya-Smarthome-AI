Authentication

Every Open API request is authenticated with your key in the X-API-Key header. All data is scoped to the house the key belongs to.


      

    


    

      
Endpoints

      

        

          GET/api/open/v1/devices
          
List every device in your house with channel states.

          

        

        

          GET/api/open/v1/devices/{device_id}
          
Get one device with its channel states.

          

        

        

          POST/api/open/v1/devices/{device_id}/command
          
Switch a channel. Body: {"cmd": "on|off|all_on|all_off", "channel": 1-3}.
